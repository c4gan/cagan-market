# 🛒 cagan-market v1.0.0 Initial Release

Welcome to the first official release of **cagan-market**, an open-source store and shopping cart system built for RedM servers supporting both **VORP Core** and **RSG-Core**.

### 🌟 Release Highlights:
- **Torn-Paper Western NUI**: Immersive 1899 dark aesthetic designed for Red Dead lore.
- **Interactive Multi-Item Shopping Cart**: Add multiple items with quantity selectors, dynamic pricing, and instant checkout.
- **Universal Framework Bridge**: True auto-detection (`Config.Framework = 'auto'`) that bridges with VORP Core or RSG-Core automatically.
- **Dual Store Modes**: Buy stores and Sell stores for material trading, hunting pelts, and butcher shops.
- **Job & Grade Restrictions**: Easily lock supply depots or armories to designated jobs.
- **Storekeeper NPCs & Map Blips**: Fully configurable peds, map blips, and hold-key prompts.
- **Discord Webhook Logging**: Detailed purchase receipts sent directly to your Discord channel.
- **Multi-Language (i18n)**: English, Turkish, German, French.

### 📦 Installation:
1. Extract `cagan-market` into your server's `resources` directory.
2. Add `ensure cagan-market` to your `server.cfg`.
3. Configure stores, items, and language in `config.lua`.
